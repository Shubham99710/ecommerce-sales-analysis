# E-Commerce Sales & Customer Insights Analysis

## Business Overview
This project analyzes online retail transection data to identify revenue trends, high-value customers segments, and repeat purchase behavior using Python, SQL, and Tableau.

## Tech Stack & Methodology
* **Python (Pandas):** Cleaned raw transactional data, handled missing customer IDs, converted date types, and calculate total order values.
* **SQL (BigQuery):** Calculated Monthly Revenue, Customer Lifetime Value, and Repeat Purchase Rate using CTEs and aggregations.
* **Tableau:** Designed an interactive executive dashboard displaying key KPIs and monthly trendlines.

## Key Insights
1. **Revenue Growth:** Identified core revenue trends and seasonal purchasing spikes.
2. **Customer Retention:** Calculated a **65.5% repeat customer rate** across the customer base.
